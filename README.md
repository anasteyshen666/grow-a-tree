# Grow a Tree

Медитативно-напряжённая стратегия на сетке: играешь за разум древнего леса,
растишь сеть светящихся корней, добываешь воду и энергию и отбиваешь
бесконечные волны жуков. Полный концепт — в [docs/GDD.md](docs/GDD.md).

**Стек:** Go + [Ebiten v2](https://ebitengine.org/). Без движка, чистый код.

## Запуск

```sh
go run ./cmd/game
```

## Сборка

```sh
go build -o bin/growtree.exe ./cmd/game
```

## Структура

```
cmd/game/            — точка входа (main), создаёт окно и запускает game loop
internal/
  game/              — корневой Game: game loop, Update/Draw, связывает подсистемы
  world/             — сетка, клетки, Ядро, корни, гниль, источники, связность сети
  resources/         — экономика: Энергия / Вода / Семена
  enemies/           — жуки: 5 уровней, pathfinding, ИИ, бой
  waves/             — менеджер волн: таймер подготовки, спавн, номер волны
  plants/            — растения-спутники (петы) и их ауры
  season/            — сезоны (лето/осень/зима/весна) и их модификаторы
  ui/                — HUD: полоски, кнопки, счётчики
  save/              — сохранение рекорда (save.json)
assets/              — плейсхолдеры/будущие текстуры (встроятся через go:embed)
config/              — json-баланс (враги, растения, сезоны, общие числа)
docs/                — GDD
bin/                 — собранный .exe (git-ignored)
```

Каждый пакет в `internal/` пока содержит `doc.go` с описанием зоны
ответственности и того, на каком этапе он наполняется. Логика добавляется
пакет за пакетом по мере прохождения этапов.
